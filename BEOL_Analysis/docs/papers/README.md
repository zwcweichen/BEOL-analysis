# docs/papers/ — 文獻 PDF 本機存放處

- 清單與下載來源：`docs/REFERENCES.xlsx`（工作表「文獻清單」的「開放 PDF 下載來源」與「本機檔名」兩欄）；主檔是 `docs/REFERENCES.md`。
- 檔名規則：`編號_第一作者或arXiv編號_年份.pdf`，例如 `11_Boning_2003.pdf`、`15_arXiv_2410.06133_2024.pdf`。
- 付費文獻（IEEE、Wiley、AIP、Annual Reviews、IBM）請自行從有訂閱的管道取得後放進來，並在 Excel「本機已存檔」欄打 V。
- 這個資料夾不進 git、不打包進產生器（版權），只有這份 README 會一起產生。
